# Waycloak v0.1.0-rc.1

`v0.1.0-rc.1` is the first release candidate for the clean-break Waycloak
architecture. It is feature complete for v0.1 and freezes the public
`networking.waycloak.io/v1beta1` schemas and behavioral contracts. The API
version is intentionally unchanged.

The signed tag resolves to exact source commit
`aee6fbe315ba05f259d1575097d01aab58127ac1`. The canonical release manifest is
`sha256:eb7124723185a5cb3b035f499e01b982cb72ab2bb1009221921bcafb9f190bcb`.
The [GitHub release](https://github.com/Amoenus/waycloak/releases/tag/v0.1.0-rc.1)
contains 37 uniquely named runtime and CLI assets.

## Included

- explicit Pod-template route enrollment and creation-time fail-closed CNI;
- shared Proton/OpenVPN gateway with observed tunnel and split-DNS readiness;
- controller-owned exact-Pod-UID bindings and node drift reconciliation;
- optional Service-backed single-active port forwarding and qBittorrent adapter;
- signed `waycloakctl` binaries for Linux, macOS, and Windows;
- signed multi-platform OCI images, Helm OCI chart, and KCL OCI module;
- downloadable chart and KCL archives, exact reference files, checksums, SPDX
  SBOMs, GitHub build provenance, and canonical signed release manifest;
- preflight, confirmation-bound install/transition, repair, certificate
  rotation, doctor, verification, support bundle, backup/restore, and alpha
  purge commands.

## Known limitations

- This is a prerelease, not the stable graduation claim.
- The supported provider quick path is Proton OpenVPN.
- Fresh independent-user completion within 15 minutes is not yet recorded.
- A prior normal uninstall completed but took 301 seconds; destructive purge is
  always separate.
- The beta.3 homelab soak was interrupted by an unrelated Raspberry Pi/CoreDNS
  node-wide stall. Waycloak withdrew readiness fail closed and recovered.
- Multi-gateway sharding/failover and Bitmagnet certification are not included.

## Upgrade

Verify this release's `release-manifest.json`, run `waycloakctl install plan`
against the existing exact release, review the generated transition, and apply
the exact plan ID. Do not use raw Helm to cross an immutable release identity.
The v1beta1 API schemas remain unchanged from the beta contract.
