# Waycloak v0.1.0-rc.9

RC.9 is the gateway-to-adapter DNS correction release candidate. It preserves
the frozen `networking.waycloak.io/v1beta1` API, generic Gluetun integration
boundary, port-forward lease contract, and workload-adapter protocol from
RC.8.

The tokenless gateway runtime now receives the installer-observed Kubernetes
cluster domain and addresses adapter Services with a fully qualified DNS name.
This avoids relying on a Pod resolver search list inside the shared VPN-engine
network namespace. The endpoint remains deterministic and mTLS authenticated;
invalid or absent cluster-domain configuration fails startup when adapter
delivery is enabled.

RC.9 also contains RC.8's handoff recovery: adapter delivery intent is durable
before application mutation, and withdrawal with no tracked mutation is an
idempotent success while mismatched generation or Pod identity still fails
closed.

RC.9 must be consumed by exact signed identity. Publication and healthy Pods
do not prove provider ingress. The homelab qBittorrent canary must demonstrate
a live provider mapping, TCP and UDP packet rules, lease delivery and
acknowledgement, the matching application listener, renewal, fail-closed
withdrawal, and recovery. This prerelease does not claim stable graduation,
the required soak, or final exact-artifact certification.
