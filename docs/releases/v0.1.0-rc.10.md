# Waycloak v0.1.0-rc.10

RC.10 is the qBittorrent 5.2 WebAPI compatibility release candidate. It
preserves the frozen `networking.waycloak.io/v1beta1` API, generic Gluetun
integration boundary, port-forward lease contract, and workload-adapter
protocol from RC.9.

qBittorrent 5.2 returns HTTP 204 for successful WebAPI operations that contain
no response data. The reference adapter now accepts that response for login
and mutation operations while retaining the HTTP 200 response used by earlier
compatible versions. A 204 response is not accepted as proof of authorization:
the adapter must successfully read the protected preferences endpoint before
it changes the application listener.

After mutation, acknowledgement still requires exact observation of the
leased listener, disabled random-port and UPnP behavior, and a successful TCP
probe to the bound application Pod. Reannouncement remains generation-bound.
These checks preserve fail-closed behavior while supporting the current
qBittorrent API contract.

RC.10 includes RC.9's fully qualified adapter Service DNS correction and
RC.8's durable handoff recovery. It must be consumed by exact signed identity.
Publication and healthy Pods do not prove provider ingress. The homelab
qBittorrent canary must demonstrate a live provider mapping, TCP and UDP packet
rules, lease delivery and acknowledgement, the matching listener, renewal,
DHT/peer operation, fail-closed withdrawal, and recovery. This prerelease does
not claim stable graduation, the required soak, or final exact-artifact
certification.
