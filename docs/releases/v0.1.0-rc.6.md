# Waycloak v0.1.0-rc.6

RC.6 is the GitOps deployment recovery release candidate. It preserves the
frozen `networking.waycloak.io/v1beta1` API and extension contracts.

Release completion continues to require the exact target gateway engine and
agent images, target release identity, current StatefulSet revision, both
containers Ready, and a current `VPNGateway Ready=True` observation. It no
longer requires every application binding behind that gateway to be Ready.
Application bindings can be unready for application-local reasons such as an
unavailable volume; coupling those conditions made a healthy product upgrade
wait until timeout. Such bindings remain fail closed and observable.

RC.6 includes the safe CNI reinstall, fixed Go 1.26.6 build boundary, and
idempotent same-revision Helm repair behavior from the preceding candidates.

This is a prerelease. It does not claim completion of the stable-graduation
epic, soak period, or final exact-artifact certification.
