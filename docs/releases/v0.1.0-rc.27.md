# Waycloak v0.1.0-rc.27

RC.27 is the dependency-backed stabilization successor to RC.26. It preserves
the frozen `networking.waycloak.io/v1beta1` API, the certified Kubernetes
`v1.36.1+k3s1` operator row, and the strict fail-closed data-plane contract.

Gluetun now owns provider port-forward acquisition and renewal. Waycloak reads
the authenticated loopback control surface and retains responsibility for
stable lease and target identities, freshness, translation, packet rules,
handoff, acknowledgement, status, and fail-closed withdrawal. No provider
protocol has moved into an application workload.

The workload-adapter protocol now separates Apply from Observe. An unchanged
mapping can be re-observed without rewriting application state, expiry-only
renewal does not call the application, and a changed mapping is applied once
before its exact generation is acknowledged. Withdrawal bypasses cached
acknowledgement.

The gateway's custom DNS server is replaced by a qualified, digest-pinned
CoreDNS v1.14.7 sidecar. This CoreDNS instance is private to the gateway; it
does not require the Kubernetes cluster itself to run CoreDNS. The cluster DNS
dependency remains the configured Service address and cluster domain, and an
alternative cluster DNS implementation is supported when it satisfies the
same mandatory cluster/external A and AAAA behavior over the required UDP and
TCP paths. Waycloak keeps its own semantic probes and withdraws readiness on
the first failed path without hysteresis or fallback.

Optional bounded OpenTelemetry signals cover gateway, provider mapping,
adapter, handoff, and withdrawal transitions. Telemetry is a true no-op by
default. The opt-in OTLP/HTTP path has a bounded non-blocking queue, fixed
low-cardinality attributes, short export deadlines, and no reconciliation or
readiness dependency. A collector remains optional and can translate the
signals for Prometheus-compatible consumption.

The release also introduces a machine-readable dependency and release-artifact
inventory with security, license, SBOM, provenance, reproducibility,
compatibility, maintenance, and resource-budget checks. Qualified dependencies
and build tools were refreshed without expanding the certified support row.
The local cluster was observed at Kubernetes `v1.36.1+k3s1`, not 1.37, so 1.37
remains an explicit compatibility qualification item rather than an RC.27
claim.

RC.27 remains a prerelease. Runtime and CLI publication, independent redownload
verification, exact homelab GitOps deployment, qBittorrent TCP/UDP listener,
port-forward, DHT and torrent checks, renewal and rotation evidence, and a new
minimum 72-hour unchanged-artifact local-cluster epoch remain mandatory before
stable graduation.
