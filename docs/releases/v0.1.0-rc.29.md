# Waycloak v0.1.0-rc.29

> **Do not deploy RC.29.** Exact homelab validation found that the
> port-forward table's unmatched-tunnel rule also dropped established TCP
> replies for ordinary protected-workload egress. The tunnel itself and UDP
> DNS remained healthy, but the forwarded TCP path failed closed. RC.30 is the
> corrective successor.

RC.29 is the publication successor to RC.28. It contains the same frozen API,
runtime implementation, dependency-backed stabilization, certified support row,
and fail-closed behavior. RC.28's images, chart, KCL module, signatures, SBOMs,
provenance, checksums, and release manifest published successfully, but its
independent redownload verifier rejected the KCL OCI manifest before declaring
the release deployable.

The qualified KCL CLI publishes module packages as gzip-compressed tar layers
and records the matching
`application/vnd.oci.image.layer.v1.tar+gzip` artifact type. RC.28's verifier
incorrectly required the uncompressed tar media type. RC.29 corrects the exact
assertion; it does not relax signature, provenance, digest, annotation, layer,
consumer-render, or asset-inventory verification.

RC.29 retains the exact-digest CoreDNS v1.14.7 qualification described in the
RC.28 notes. Its bounded Trivy exception remains limited to the eleven reviewed
findings for that one digest, expires on 2026-11-27, and is not a global
vulnerability waiver.

RC.29 remains a prerelease. Runtime and CLI publication, independent redownload
verification, exact homelab GitOps deployment, qBittorrent TCP/UDP listener,
port-forward, DHT and torrent checks, renewal and rotation evidence, and a new
minimum 72-hour unchanged-artifact local-cluster epoch remain mandatory before
stable graduation.
