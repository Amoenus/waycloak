# Waycloak v0.1.0-rc.4

`v0.1.0-rc.4` is the publishable deployment hotfix following RC.2. It contains
the CNI reinstall correction documented for RC.3 and builds every Go artifact,
including the derived Gluetun binaries, with Go 1.26.6.

RC.3 runtime publication was blocked before signing by the release
vulnerability gate because Go 1.26.5 was affected by GO-2026-6218,
GO-2026-6090, GO-2026-6089, and GO-2026-5972. All four are fixed in Go 1.26.6.
RC.4 raises the repository toolchain floor rather than adding a vulnerability
exception.

The frozen `networking.waycloak.io/v1beta1` API and RC.2 engine/application
extension contracts are unchanged. Use the normal confirmation-bound
transition or journal-bound repair path; do not mutate host CNI recovery files
manually.
