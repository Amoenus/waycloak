# Waycloak v0.1.0-rc.30

RC.30 corrects the forwarded-egress regression found during exact RC.29
homelab validation. RC.29's port-forward nftables table accepted exact active
lease ingress and then denied every other packet arriving from the tunnel.
Because nftables evaluates every base chain on the forwarding hook, that final
drop also consumed established TCP replies that the gateway-core table had
already accepted for ordinary protected-workload egress.

The port-forward table now explicitly accepts only conntrack
`established,related` packets from the tunnel to the overlay before retaining
the unmatched-tunnel drop. New unsolicited tunnel ingress, inactive leases,
stale generations, startup, tunnel loss, and gateway replacement remain fail
closed. The privileged network-namespace test now exercises ordinary outbound
TCP and its tunnel return path alongside exact TCP/UDP ingress, handoff, and
withdrawal.

RC.30 preserves the frozen `networking.waycloak.io/v1beta1` API, the delegated
Gluetun acquisition/renewal boundary, the qualified private CoreDNS gateway
sidecar, adapter Apply/Observe semantics, no-op-by-default OpenTelemetry, and
the Kubernetes v1.36 certified row. The internal CoreDNS sidecar continues to
forward through the configured cluster DNS Service and is agnostic to the
cluster's DNS implementation.

RC.30 remains a prerelease. Signed runtime and CLI publication, independent
redownload verification, exact homelab GitOps deployment, full qBittorrent and
fail-closed validation, renewal and rotation evidence, and a new minimum
72-hour unchanged-artifact local-cluster epoch remain mandatory before stable
graduation.
