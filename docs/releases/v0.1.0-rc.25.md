# Waycloak v0.1.0-rc.25

RC.25 is the turnkey GitOps-lifecycle successor to RC.24. It preserves the
frozen `networking.waycloak.io/v1beta1` API, runtime behavior, configuration
semantics, generated Kubernetes resources, signed support row, fail-closed data
plane, Gluetun integration, and stable workload-adapter protocol.

RC.24 passed publication, independent verification, exact homelab GitOps
deployment, and live qBittorrent checks. That transition also demonstrated the
intended security boundary: Kubernetes rejected an in-place digest change to
the immutable `WorkloadAdapter` trust record, and Waycloak withdrew adapter and
lease readiness until GitOps recreated the record at its stable name. The
qBittorrent Pod did not restart.

The RC.24 signed documentation did not describe that replacement transaction.
RC.25 adds a controller-neutral exact-UID procedure and explains why Argo CD
`Replace=true` alone cannot rotate an immutable spec and why
`Force=true,Replace=true` must not remain in steady desired state. It explicitly
rejects broad application replacement and out-of-band trust edits. README, Getting Started,
configuration, documentation navigation, roadmap, project status, and the
local-cluster soak example all select this one exact candidate.

The runtime and CLI publication workflows, independent redownload verifier,
exact homelab GitOps deployment, live qBittorrent checks, and a fresh minimum
72-hour unchanged-artifact local-cluster epoch all remain mandatory before
stable graduation. RC.24 observations remain lifecycle evidence but contribute
no elapsed RC.25 soak time.
