# Waycloak v0.1.0-rc.5

RC.5 is the lifecycle-recovery release candidate. It preserves the frozen
`networking.waycloak.io/v1beta1` API and the RC.2 extension contracts.

The release fixes one idempotency edge case in `waycloakctl install repair`.
After the exact failed Helm revision is deleted, Helm may reuse that revision
number for the successful target. If the CLI is interrupted after Helm returns
but before journal cleanup, a resumed repair now distinguishes that deployed
record from the deleted failed record and verifies the complete exact target
state before removing the immutable repair and transition journals. A changed
pending or failed record is still rejected.

RC.5 includes the RC.3 safe CNI reinstall behavior and the RC.4 Go 1.26.6
runtime/toolchain security fix. Use the normal confirmation-bound transition
or its journal-bound repair path. Do not remove lifecycle journals or mutate
host CNI recovery files manually.

This is a prerelease. It does not claim completion of the stable-graduation
epic, soak period, or final exact-artifact certification.
