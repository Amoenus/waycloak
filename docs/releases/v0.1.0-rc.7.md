# Waycloak v0.1.0-rc.7

RC.7 is the optional-capability activation release candidate. It preserves the
frozen `networking.waycloak.io/v1beta1` API, generic Gluetun integration
boundary, port-forward lease contract, and workload-adapter protocol from
RC.6.

The distinct signed release identity allows an installer-managed replacement
of an immutable gateway class when an operator enables the already published
gateway runtime and qBittorrent reference adapter. Port forwarding remains
disabled by default. A deployment must explicitly request the gateway
capabilities, create a `PortForwardLease`, and select an approved immutable
adapter image when application-local configuration is required.

RC.7 does not treat image publication, rendered resources, or Pod readiness as
proof that provider ingress works. The homelab canary must demonstrate a live
provider mapping, TCP and UDP packet rules, lease delivery and acknowledgement,
the matching qBittorrent listener, renewal, fail-closed withdrawal, and
recovery. This prerelease does not claim completion of the stable-graduation
epic, soak period, or final exact-artifact certification.
