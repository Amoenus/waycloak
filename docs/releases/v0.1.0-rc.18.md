# Waycloak v0.1.0-rc.18

RC.18 is the release-coordination successor to RC.17. It contains the same
authoritative PortForwardLease reconciliation and transition diagnostics, and
preserves the frozen `networking.waycloak.io/v1beta1` API and immediate
fail-closed behavior.

RC.17's exact main CI and CLI publication passed. Its runtime workflow also
completed reproducible builds, vulnerability policy, SBOM generation,
signatures, and attestations, but its final uploader lost a creation race with
the CLI workflow. Replaying that workflow correctly stopped at the already
published immutable KCL version. RC.17 is consequently not a complete runtime
release and is not a deployment candidate.

RC.18 makes the CLI and runtime publishers address their shared GitHub release
by the explicit immutable tag name. OCI artifact immutability remains intact;
no RC.17 asset is reconstructed or promoted outside the attested workflow.

RC.18 must pass exact main CI, both release workflows, and both independent
clean-download verifiers before GitOps deployment. It must then hold one
PortForwardLease generation through a fresh stabilization window before the
minimum 72-hour local-cluster soak begins. qBittorrent is the sole application
canary, Bitmagnet remains at zero, and no additional cluster node is required.
