# Waycloak v0.1.0-rc.11

RC.11 is the exact provider-ingress firewall composition release candidate.
It preserves the frozen `networking.waycloak.io/v1beta1` API, generic Gluetun
integration boundary, port-forward lease contract, and workload-adapter
protocol from RC.10.

RC.10 proved provider mapping, application delivery, exact qBittorrent
listener configuration, renewal, and DHT operation. A subsequent independent
external probe showed that Proton-delivered new inbound packets still met the
drop policies of the separate Gluetun and baseline Waycloak forward chains.

The lease-owned prerouting chain now assigns a reserved packet mark only after
matching an exact active provider-internal port and protocol. Both baseline
forward chains admit new tunnel-to-overlay traffic only with that mark. The
mark is local packet metadata, is not supplied by a remote peer or workload,
and cannot outlive the packet. Unmatched tunnel ingress and all withdrawn
leases remain fail closed.

The privileged TCP/UDP packet-path acceptance now composes the lease rules
with two independent drop-policy baseline chains, reproducing the production
topology that exposed the defect. RC.11 also contains RC.10's qBittorrent 5.2
no-content WebAPI support, RC.9's fully qualified adapter Service DNS, and
RC.8's durable handoff recovery.

RC.11 must be consumed by exact signed identity. The homelab canary must
reproduce independent external TCP reachability, observe external UDP ingress,
and retain lease acknowledgement, listener, renewal, DHT, fail-closed
withdrawal, and recovery evidence. This prerelease does not claim stable
graduation, the required soak, or final exact-artifact certification.
