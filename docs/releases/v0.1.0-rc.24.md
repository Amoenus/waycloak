# Waycloak v0.1.0-rc.24

RC.24 is the turnkey-documentation successor to RC.23. It preserves the frozen
`networking.waycloak.io/v1beta1` API, runtime behavior, configuration semantics,
generated Kubernetes resources, signed support row, fail-closed data plane,
Gluetun integration, and stable workload-adapter protocol.

RC.23 passed publication and live exact-artifact checks, and qBittorrent
remained operational with Proton port forwarding, DHT, and real torrent upload.
Its graduation epoch was invalidated because user-facing guidance still
selected older RC.13 and RC.11 artifacts. A healthy runtime does not satisfy
turnkey certification when a new user is directed to a different release.

RC.24 aligns README, Getting Started, configuration, documentation navigation,
release scope, project status, and the local-cluster soak example on one exact
candidate. It also removes product-edition wording from retained PRD text. It
does not relax any failure criterion or inherit RC.23 elapsed soak time.

The runtime and CLI publication workflows, independent redownload verifier,
exact homelab GitOps deployment, live qBittorrent checks, and a fresh minimum
72-hour unchanged-artifact epoch all remain mandatory before stable graduation.
