# Waycloak v1.0.1

`v1.0.1` is the first stable Waycloak release approved for deployment. It
replaces `v1.0.0`, whose runtime artifacts failed the release vulnerability
policy and must not be deployed.

## Certified support

- Kubernetes `v1.36.1+k3s1`
- K3s with Flannel and `containerd://2.2.3-k3s1`
- Linux kernel 5.10 or newer on `amd64`
- Gluetun with Proton/OpenVPN
- protected TCP, UDP, and DNS
- single-active provider port forwarding and the optional workload-adapter
  handoff

The stable qualification accepted the RC42 evidence with a documented one-time
36.920183-hour soak waiver rather than the normal 72-hour clean epoch. This is
release evidence, not a relaxation of the runtime fail-closed contract.

## Installation

Follow [Getting started](../getting-started.md). Installation, upgrade, and
rollback require a verified `waycloakctl install plan/apply` transaction. Helm
remains the packaged installation surface, and KCL remains optional for typed
user-resource authoring.

## API and safety contract

- API version: `networking.waycloak.io/v1beta1`
- enrollment: Pod-template label
  `networking.waycloak.io/egress-route: <same-namespace-route>`
- protected traffic never falls back to ordinary egress
- credentials remain referenced from the gateway and are not copied to
  workloads
- `Ready=True` represents current observed data-plane health
- no mutable `latest` artifacts are part of the release

Waycloak provides selected, fail-closed VPN egress within the documented threat
model. It does not claim anonymity.
