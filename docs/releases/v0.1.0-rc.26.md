# Waycloak v0.1.0-rc.26

RC.26 is the stability successor to RC.25. It preserves the frozen
`networking.waycloak.io/v1beta1` API, configuration contracts, support row,
fail-closed data plane, Gluetun integration, and workload-adapter protocol.

RC.25 completed its exact 72-hour local-cluster qBittorrent interval with fixed
release, GitOps, and Pod identities and zero restart increases. It did not pass
graduation. The retained evidence found that unchanged port-forward
reconciliation reacquired the Proton NAT-PMP mapping on every pass. The changing
expiry rewrote lease status, immediately requeued the controller, and repeatedly
redelivered the same qBittorrent adapter record. The interval consequently
recorded excessive resource writes, hundreds of listener-probe timeouts, and
brief fail-closed lease withdrawals.

RC.26 retains the provider's internal `RenewAfter` observation and reuses the
last valid mapping until that boundary. Scheduled renewal still advances the
expiry, failed renewal retains an unexpired mapping for bounded retry, and an
expired or invalid mapping still removes rules fail closed. No provider-specific
field is added to the Kubernetes API.

The gateway's five mandatory DNS checks now execute in deterministic sequence
instead of simultaneously against the same local proxy and upstreams. Cluster A
over UDP/TCP and external A/AAAA over UDP plus external A over TCP remain
mandatory. The first failed checked path immediately withdraws readiness; the
existing retries, deadlines, response validation, RCode and latency diagnostics,
deny rules, and recovery transitions remain intact. There is no permissive
hysteresis. A genuine multi-protocol outage like the 60-second RC.25 event still
fails closed.

The released soak collector now serializes an absent-provider sample with its
actual gateway, lease, listener, and DNS conditions and a bounded failure phase.
It no longer loses that state while formatting a missing expiry and never writes
the provider public endpoint.

RC.26 remains a prerelease. Runtime and CLI publication, independent redownload
verification, exact homelab GitOps deployment, qBittorrent TCP/UDP listener,
port-forward, DHT and torrent checks, packet evidence, and a fresh minimum
72-hour unchanged-artifact local-cluster epoch remain mandatory before stable
graduation.
