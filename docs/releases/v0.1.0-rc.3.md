# Waycloak v0.1.0-rc.3

`v0.1.0-rc.3` is the deployment hotfix for RC.2. It preserves the frozen
`networking.waycloak.io/v1beta1` API and all extension-contract changes from
RC.2.

## Fix from RC.2

An RC.2 transition could stop fail closed when the active primary CNI conflist
had already been restored to its unchained form while the valid
`.waycloak-original` recovery copy remained. The installer attempted to create
the recovery copy exclusively and rejected the existing file before it could
reinstall the chained config, binary, and signed receipt.

RC.3 accepts that state only when the existing regular recovery file is
byte-for-byte identical to the active unchained primary config. It retains the
file and continues the exact release-bound install. A missing, non-regular, or
different recovery file remains a hard failure. No permissive CNI adoption or
ordinary-egress fallback is introduced.

Use the normal confirmation-bound transition or its journal-bound repair path.
Do not remove or rename the recovery copy manually.
