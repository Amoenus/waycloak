# Waycloak v0.1.0-rc.8

RC.8 is the adapter-handoff recovery release candidate. It preserves the
frozen `networking.waycloak.io/v1beta1` API, generic Gluetun integration
boundary, port-forward lease contract, and workload-adapter protocol from
RC.7.

The qBittorrent reference adapter now persists a delivery intent before it
mutates the application. If the application call fails, the durable pending
record gives a later withdrawal enough information to restore the configured
backend port. If no adapter mutation was ever tracked, withdrawal is an
idempotent success. A withdrawal with a mismatched generation or Pod identity
is still rejected. Runtime and adapter diagnostics identify failed operations
and lease identities without exposing credentials.

RC.8 must be consumed by exact signed identity. The release includes the CLI,
multi-platform runtime images, Helm OCI chart and downloadable chart, optional
KCL OCI schema module and downloadable module, checksums, SBOMs, provenance,
and the signed canonical release manifest.

Publication and healthy Pods do not prove provider ingress. The homelab
qBittorrent canary must demonstrate a live provider mapping, TCP and UDP packet
rules, lease delivery and acknowledgement, the matching application listener,
renewal, fail-closed withdrawal, and recovery. This prerelease does not claim
completion of the stable-graduation epic, soak period, or final exact-artifact
certification.
