# Waycloak v0.1.0-rc.19

RC.19 is the resilient-publication successor to RC.18. It retains RC.17's
authoritative PortForwardLease reconciliation, transition diagnostics, frozen
`networking.waycloak.io/v1beta1` API, and immediate fail-closed behavior.

RC.18 passed exact main CI and its CLI clean-download verifier. Its runtime
workflow produced every image, package, SBOM, signature, provenance statement,
and canonical manifest, but GitHub returned HTTP 503 for every final upload
attempt. Because its immutable KCL version is already published, RC.18 is not
replayed and is not a deployment candidate.

RC.19 publishes the shared GitHub release through a repository-owned `gh`
transaction bound to the exact tag. It tolerates either publisher winning the
creation race, retries transient API failures with bounded backoff, and
replaces only same-named downloadable assets. OCI versions remain immutable.

Both release workflows and their independent clean-download verifiers must
pass before RC.19 enters homelab GitOps. A stable-generation qBittorrent window
must then pass before the minimum 72-hour local-cluster soak can begin.
